# Figma Implementation

## 3. Primary Figma design reference
Use the following Figma design as the primary visual reference for the content after the hero:

https://www.figma.com/design/pXhoqvfomsbzF6DwgQiCPE/Viralytics---Social-Media-SaaS-Website-UI-Figma-Template--Community-?node-id=52-1285

Use the Figma MCP integration when available to inspect:

- Screenshots and visual composition.
- Section hierarchy.
- Typography and font weights.
- Card geometry and border radii.
- Spacing and alignment.
- Background colors.
- Button styling.
- Decorative elements.
- Grid systems.
- Image positioning.
- Responsive layout behavior.

Do not merely take inspiration from the design and generate unrelated sections.

Faithfully reproduce its visual language, composition and design patterns while adapting its content to a cybersecurity professional.

Preserve the structure and aesthetic of the reference, but remove irrelevant SaaS marketing content.

If the Figma integration is unavailable, report this limitation instead of pretending the design has been inspected.

## Verification

Inspect the actual frames and screenshots before implementation. Extract layout, typography, assets and tokens; map each section to portfolio content. Compare browser screenshots against the reference. Do not use screenshots as implementation assets. Preserve the existing hero.
