# Engineering Rules

## 10. Engineering requirements
Preserve the existing framework and architectural conventions.

If the project uses Next.js and React:

- Use server components where appropriate.
- Use client components only where interaction or animation requires them.
- Avoid marking the entire application as a client component.
- Use optimized image components where appropriate.
- Maintain correct metadata and semantic HTML.

General requirements:

- Reusable section components.
- Centralized design tokens.
- Centralized professional content.
- Typed data models.
- Responsive layouts.
- Accessible interactive components.
- Optimized local assets.
- Minimal unnecessary dependencies.
- No broken links.
- No hydration errors.
- No horizontal overflow.
- No console errors.
