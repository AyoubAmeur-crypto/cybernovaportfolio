- Correct synchronization with ScrollTrigger.
- No duplicate requestAnimationFrame loops.
- Proper cleanup when components unmount.
- Smooth anchor navigation.
- Compatibility with mobile scrolling.
- Respect `prefers-reduced-motion`.
- Maintain keyboard navigation and native accessibility.

Motion direction:

- Subtle text reveals.
- Carefully staggered section entrances.
- Controlled image reveals.
- Minimal parallax where appropriate.
- Seamless hero-to-content transition.
- Smooth navbar state changes.
- Refined button hover interactions.

Use animations to support visual hierarchy, not distract from it.

Avoid scroll hijacking, unnecessary pinned sections, forced horizontal scrolling and excessive animation durations.

Target smooth, stable scrolling at approximately 60 FPS on capable devices.
