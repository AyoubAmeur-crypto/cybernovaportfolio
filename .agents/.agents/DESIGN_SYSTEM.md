# Design System

## 5. Visual direction
Create a premium, modern, editorial cybersecurity portfolio.

The visual identity should balance technical expertise, professionalism and elegance.

Initial brand colors from the README:

- Dusty rose: `#D4879C`
- Deep navy: `#1A1A2E`

Reconcile these colors with the existing hero and the Figma design.

Use the Figma reference to determine background colors, surface treatments and layout patterns.

Avoid:

- Generic hacker aesthetics.
- Green Matrix-style interfaces.
- Excessive terminal components.
- Cyberpunk neon effects.
- Excessive gradients.
- Unnecessary glowing borders.
- Emoji decorations.
- Generic AI-generated illustrations.
- Repetitive card grids.
- Excessive rounded containers.
- Glassmorphism across the entire page.

The portfolio must look designed, not assembled from a generic component library.

## 6. Apple-inspired navigation bar
Redesign or refine the navigation bar using an Apple-inspired Liquid Glass aesthetic.

Requirements:

- Floating navigation bar.
- Translucent surface.
- Controlled backdrop blur and saturation.
- Subtle reflective highlights.
- Thin adaptive border.
- Soft realistic shadow.
- High text readability over different backgrounds.
- Smooth appearance changes during scrolling.
- Responsive mobile navigation.
- Active section indication.

Suggested navigation:

- Home
- About
- Expertise
- Projects
- Contact

Include a professional contact CTA.

The navbar is the only primary component that should use the Liquid Glass visual treatment.

Buttons must NOT be glassy.

Buttons should follow the original Figma reference using normal solid fills, outlined variants, appropriate radii and refined hover states.

Do not use expensive or experimental glass effects that negatively impact scrolling performance.

## 7. Hero-to-content transition
The existing hero must flow naturally into the new sections.

Avoid an abrupt visual boundary between the hero and the content.

Analyze the hero's final background, composition and animations before designing the transition.

Create a coordinated transition using a combination of:

- Smooth background color continuity.
- Controlled vertical spacing.
- Subtle content reveals.
- Carefully timed opacity and transform animations.
- Optional decorative elements consistent with Figma.

Do not introduce a heavy fullscreen animation or artificial loading sequence between sections.

Preserve the user's ability to scroll naturally.
